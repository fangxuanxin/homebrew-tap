# fangxuanxin/homebrew-tap

Homebrew casks for apps by fangxuanxin.

```sh
brew install --cask fangxuanxin/tap/clashbar
```

| Cask | App |
| --- | --- |
| `clashbar` | [ClashBar](https://github.com/fangxuanxin/ClashBar) — menu bar app showing the exit region of Clash, Mihomo and sing-box |

## 中文

```sh
brew install --cask fangxuanxin/tap/clashbar
```

升级：`brew upgrade --cask clashbar`；卸载并清理设置：`brew uninstall --zap --cask clashbar`。
